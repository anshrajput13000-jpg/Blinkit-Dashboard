# 🟡 Blinkit Grocery Sales Dashboard (Power BI)

## 📘 Overview
This repository contains an interactive **Power BI dashboard** analyzing Blinkit grocery sales data.  
It provides insights into total sales, average ratings, outlet performance, and product category trends — enabling data‑driven decision making for retail operations.

---

## 📊 Key Features
- Total sales and average rating metrics  
- Year‑wise sales trend visualization (2015–2020)  
- Outlet‑wise and tier‑wise performance comparison  
- Product category breakdown by fat content and item type  
- Dynamic filters for outlet size, tier, and product category  
- Clean, responsive dashboard layout  

---

## 🧠 Tech Stack
- Power BI Desktop  
- Blinkit Grocery Dataset  
- DAX & Power Query for data modeling  
- Interactive visuals and slicers
